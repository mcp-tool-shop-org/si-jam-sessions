# Lane 2 — music representation and evaluation for LLMs (Opus research seat, 2026-09-25; retrieval claimed, NOT yet gated)

(abs) = abstract number, (body) = paper body. MusICA per-model figures dropped (two reads disagreed). Not opened: ZIQI-Eval, text2midi. MuPT (arXiv:2404.06393) reports no SMT-ABC vs plain-ABC test and no memorisation check (body).

1. Wang et al. 2025, NotaGen, arXiv:2502.18008 — trains on interleaved ABC (bar-aligned voices), 15-key augmentation; after CLaMP-DPO perplexity ROSE yet 92 music-college listeners preferred outputs; authors: PPL not a suitable metric (body §3.1, §3.3, §4.2). → bar-interleaved ABC for scores; never gate on perplexity.
2. Wu, Kim & Huang 2025, MIDI-LLM, arXiv:2511.03942 — note triples (onset, 10 ms duration, instrument×pitch) added to Llama vocab because MIDI-as-text is too long; FAD 0.173 vs Text2midi 0.818 (body Table 2); no human study, no dedup; test set from MidiCaps (Melechovsky, Roy & Herremans 2024, arXiv:2406.02255) built on Lakh. Triples from Thickstun, Hall, Donahue & Liang 2023, Anticipatory Music Transformer, arXiv:2306.08620 — interleaves fixed control events for infilling/accompaniment (abs). → accompaniment = model proposes events against controls the law holds fixed.
3. Guo & Dixon 2025, Moonbeam, arXiv:2505.15559 — one compound token per note with ABSOLUTE onsets because transformers struggle with arithmetic over time-shifts (body). CLaMP 3 (Wu et al. 2025, arXiv:2502.10362) — ABC for scores, lossless MIDI Text Format for performances (body §2.2). → score = ABC; performance = absolute-onset events.
4. Fradet, Gutowski, Chhel & Briot 2023, arXiv:2310.08497 — bar/position tokens: time-syntax error rate 0.113–0.127; time-shift tokens cannot make that error; explicit durations beat NoteOff (body Table 2). Fradet et al. BPE, arXiv:2301.11975 — REMI sequences 45–64% shorter (body Table 1). Xu 2026, Libretto, arXiv:2606.22708 (single-author preprint) — recovering onsets from ABC took 70 running additions over 98 notes; duration edits cascade into 1,005 onset re-derivations vs 0 with explicit onset slots; measure-and-revise loop 6/51 → 20/51 gap-fill passes (body Tables 1, 3). → corrections target (onset, duration) slots, not ABC text.
5. Carone, Ripollés & Roman 2025, arXiv:2510.22455 — Gemini 2.5 Pro from MIDI-as-text: 95% syncopation, 97.73% chord quality; from audio: 25% and 47.73% (body Table 1). → measuring is the law's job; once measured, judging is nearly free (fits the sibling's 97% base).
6. Dai et al. 2025, Musical Score Understanding Benchmark, arXiv:2511.20697 — best ABC-text model 49.44% vs best PDF-image 24.22% on the same questions; title-only control weak; split by piece (body §5, Tables 2, 4). Sourada, Vendrame & Hajič 2026, arXiv:2607.06015 — symbolic > image > audio averaged over models (body §7.1). Counter: Daswani et al. 2024, arXiv:2410.02637 — plots beat raw numbers by up to 120% on trend tasks (abs). → no piano-roll images in training observations; images only for contour questions.
7. Pond & Fujinaga 2025, arXiv:2503.22853 — across ABC/Humdrum/MEI/MusicXML, MEI best without context (52%) and with (75%) (abs). → for READING, explicit field-labelled formats beat compact ABC.
8. Kumar, Karystinaios, Widmer & Schedl 2026, arXiv:2601.22764 — SFT cut Musicpile-short PPL 693.9 → 36.3 while FMD worsened 66.5 → 362.1; FMD "does not exhibit clear trends" (body Table 2). Kader, Rafi, Sajjad & Karmaker 2026, arXiv:2606.05522 — across 9 models ABC syntax accuracy r = −0.06 with human-rated style accuracy; only KL divergence tracked humans (r = −0.73, p < 0.05) (body §5.2.3). → syntax validity admits, it does not score; A/B with musicians + measured task errors.
9. Choi, Kim, Ryu, Nam & Jeong 2025, arXiv:2509.16662 — Lakh: hashing finds 26,167 duplicates; learned similarity ≥ 38,134 (~21% of 178,561) from re-arrangements, tempo/offset/track edits; listeners confirmed 72.9% (body Table 5, §6.4); Moonbeam's ablation uses a random 5% Lakh test set (the leak). Long et al. 2024 PDMX, arXiv:2409.10831 — removing ~60% duplicates had little effect on harmonic/rhythmic variation (body). Ji et al. 2025, arXiv:2509.13658 — detects exact copying down to one bar (abs). → dedup buys a valid evaluation, not better music.

Recommendation (seat): Observe = a law-emitted event table (absolute onset in beats and ms, duration, pitch, cents deviation, velocity, voice) with each measurement as digits against its named gate; ABC secondary; no images. Act = bar-interleaved ABC for composing; checker-admitted slot edits (onset, duration, pitch) for corrections and accompaniment; targets state the comparison in digits. Split = by work cluster (similarity ignoring transposition/arrangement/tempo), never by record or take; augment only after splitting; every eval carries a title-only or measurement-removed baseline and a one-bar copy check against training.
