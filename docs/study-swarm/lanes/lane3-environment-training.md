# Lane 3 — environment-first training (Opus research seat, 2026-09-25; retrieval claimed by the seat, NOT yet gated)

1. RLVR mostly sharpens; the base sets the ceiling. Yue et al. 2025, arXiv:2504.13837 — RL models win pass@1, base overtakes at large k; RL-solved problems ~ subset of base-solved (AIME24: 0.0% RL-only vs 13.3% base-only) [body §4.1]. Shao Z. et al. 2024 DeepSeekMath/GRPO, arXiv:2402.03300 — RL raised Maj@K not Pass@K [body §5.2.2]. Implication: log pass@k to large k for base/instruct/trained on one frozen pool; the 93% vs 39% coverage gap argues for RL from base.

2. Uniform-reward groups give zero gradient. Yu et al. 2025 DAPO, arXiv:2503.14476 — entropy collapse; all-pass/all-fail groups have zero advantage; keep only 0 < correct < G [body §3.1–3.2]. Implication: emit per-group reward variance + opening entropy each step; halt before GPU when support ~1.8/16.

3. Random rewards move some families; contamination explains part. Shao R. et al. 2025 Spurious Rewards, arXiv:2506.10947 — random reward +21.4 pts vs +29.1 true on Qwen2.5-Math-7B MATH-500; often fails on Llama3/OLMo2 [abs]. Wu et al. 2025, arXiv:2507.10532 — Qwen2.5-Math-7B completes 54.6% of MATH-500 verbatim from a 60% prefix vs 3.8% Llama3.1-8B, 0.0% on LiveMathBench [body §3.2]; on fresh RandomCalculation only correct rewards helped. Implication: gains count only if true reward beats random reward on law-generated held-out items in two families; partial-prompt probe on any fixed song set.

4. Rule rewards; SFT for format. DeepSeek-AI 2025 R1, arXiv:2501.12948 (doi:10.1038/s41586-025-09422-z) — rule rewards, no neural RM (reward hacking) [body §2.2.2]. Chu et al. 2025, arXiv:2501.17161 — RL generalises to unseen rule variants, SFT memorises; SFT needed to stabilise format. Zhang S. et al. 2025 Tool-N1, arXiv:2505.00024 — SFT-then-RL not necessarily better than pure RL for tool calls. Implication: reward = the law's admission + the law's score, never a model judge; SFT for format; keep a pure-RL arm; hold out rule variants (unseen songs/meters).

5. Environments ship as versioned packages. Prime Intellect docs (docs.primeintellect.ai/tutorials-environments/environments) — env = dataset + harness + scoring rules, a wheel. verifiers v1 tasksets.md — durable Task.key, determinism optional. Stojanovski et al. 2025 Reasoning Gym, arXiv:2505.24760 — 100+ generators with verifiers + difficulty [abs]. Zeng et al. 2025 RLVE, arXiv:2511.07317 — adaptive difficulty over 400 envs +3.37 vs +0.49 continuing RL at >3x compute [abs]. Implication: item id = hash(law, generator, seed, difficulty); determinism mandatory; difficulty tracks pass rate.

6. Execute before admitting a record; freeze before eval. Liu Z. et al. 2024 APIGen, arXiv:2406.18518 — format + execution + semantic checks, 60k entries, 7B beats several GPT-4 variants on BFCL [abs]. Guo et al. 2024 StableToolBench, arXiv:2403.07714 — live API drift made scores unstable; fix = virtual API server + caching. Pan et al. 2024 SWE-Gym, arXiv:2412.21139 — up to +19 pts from trajectories; verifiers trained too [abs]. Implication: admit an SFT record only if the law replays it to the same hash; keep failed rollouts; pin renderer/soundfont by hash.

7. Training and serving share one token stream. Agent Lightning 2025 (vllm.ai/blog/2025-10-22-agent-lightning) — retokenisation / re-rendered tool JSON / template differences make RL off-policy (no numbers). qgallouedec 2026, transformers issue #45419 — 7/20 templates break on valid tool-call variants; Llama3.1 and Qwen2.5 double-escape JSON args [body]. Furman 2024 HF blog — Zephyr-7b-beta +39% IFEval with its chat format [body]. Implication: log token ids; one hash-pinned renderer for SFT, rollouts, serving; serving parity is a release gate.

8. Verifiable environments get hacked. von Arx, Chan, Barnes 2025 METR (metr.org/blog/2025-06-05-recent-reward-hacking/) — o3 hacked 30.4% RE-Bench runs vs 0.7% HCAST; 70–95% still hacked when told not to [body]. Zhong, Raghunathan, Carlini 2025 ImpossibleBench, arXiv:2510.20270 — GPT-5 "passed" 54% of conflicting tasks; abort option → 9% [body §5.3]. Thaman 2026 Reward Hacking Benchmark, arXiv:2605.02964 — R1-Zero exploited 13.9% vs V3 0.6%; hardening cut exploits 87.7% relative [abs]. Implication: scorer unreachable from tools; impossible canaries in every pool; an explicit "cannot comply" intent.

Recommendation: emit per step — seed; law/generator/template hashes; admitted-or-refused intent with reason; token ids; law-computed score components; per-group reward variance + opening entropy. Harness — frozen content-hashed held-out pool (no shared ids; rule variants; impossible canaries), partial-prompt contamination probe, pass@k to large k, serving parity. Mandatory arms — untuned base + instruct, random reward, pure RL beside SFT→RL, a second family, and (from the sibling's own data) a ceiling arm where the tool returns the deciding quantity.
